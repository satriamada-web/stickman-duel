# Stickman Duel

Game fighting 2D berbasis Godot 4 untuk Android.

## Konsep
- Pertarungan stickman 1 vs 1.
- Mode offline melalui Wi-Fi hotspot / LAN.
- Pemain memilih karakter dan bertarung menggunakan senjata serta skill.
- Tidak membutuhkan internet saat bermain di jaringan lokal.

## Teknologi
- Godot Engine 4
- GDScript
- ENet Multiplayer API (direncanakan untuk multiplayer LAN)

## Status pengembangan
**Tahap 1 — Fondasi proyek:** konfigurasi Godot dan prototipe arena dasar.

Fitur multiplayer LAN, pemilihan karakter, senjata, dan skill akan ditambahkan bertahap setelah prototipe dasar diuji.

## Menjalankan
1. Instal Godot Engine 4.
2. Pilih **Import**.
3. Pilih file `project.godot`.
4. Tekan **Run Project**.

## Kontrol prototipe
- KIRI / KANAN: bergerak.
- BERHENTI: menghentikan gerakan.
- SERANG: menyerang lawan latihan.

> Ini adalah prototipe awal, belum versi multiplayer final.
